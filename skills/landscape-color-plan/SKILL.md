# 景观彩平绘制

完成几何可信、材质可追溯、空间主次和植物层次可读的彩平。默认目标为 L2，实际完成度须由成图确认；用户明确的种植设计、风格和交付范围优先。仅要求对比或诊断时，查看成图与样例并提出有位置依据的修改意见，不自动重绘。仅维护 skill 时，改进规则与验收依据；运行绘制程序、操作 Photoshop 和修改成图不属于这项工作。

## 定位输入和素材库

区分本次目标设计、可选的效果参考和素材库，确定最新有效版本、场地范围、输出尺寸、坐标与单位。目标设计决定建筑、路径、水域和场地几何；效果参考只辅助判断表现。效果图缺失或不准确都不阻止填色，不要求用户先找准样例。需要补 CAD 时读取已安装的 cad skill；用户要求的曲线使用原生 SPLINE，闭合和边缘补线在填色前完成。

先采用用户明确的表现要求。有明确效果参考时，用其适用于本图的特点校准风格；仅为大致意向时提取色彩气质、植物表现或光影强弱，并指出不适用的部分。没有效果参考时，根据场地类型、功能主次、展示用途与图幅，自主确定表达方向和配色，库内样例支持工艺选择。三种情况都要通过空间主次、明暗、色彩与材质的独立检查，不能仅靠“像某张图”判定好坏。

素材库以用户本次指定位置为先，否则使用 [local-library.json](references/local-library.json) 定位配套库：解析配置文件真实路径，相对 library_root 以配置所在目录为基准，绝对路径直接使用。读取素材规范、风格配置、构图参数与自动调用约定；用库内 tools/materials.py 按风格、角色或 ID 查询素材索引。路径失效时先检查当前项目约定和实际文件，定位后继续；所需源文件确实缺失再说明缺项。

P/rural 用于自然乡村；R/residential 用于住宅；M/landscape 用于曲线景观与水景；U/park 用于城市公园与活动场地。先定主风格，跨库按已登记配方匹配色阶、光向与用途。只置入已核验的 texture / symbol；reference 用于对照。

先核对关键分区的功能与材料依据，尤其是高饱和节点和套叠轮廓。颜色、曲线形状、闭合区域或泛称 NODE 的图层不能独自证明它是屋面、花境或活动铺地；保留已确认内容，对未定部分记录待核项，继续其他已明确区域。不能靠反复取参考图颜色代替功能识别。

当目标设计、表达方向或适用参考强调曲面体量、草坡起伏、构件厚度和明显投影时，读取 [体积、地形与统一光影](references/volume-and-lighting.md)。在已有素材风格上选择分层绘制、局部简模渲染或混合方式，按对象分配；普通平涂彩平不要求建模。先判断哪些只是表现差异，哪些需要补充设计依据，不能从参考图照搬建筑、活动场或地形。

## 先组织画面，再填素材

绘制前读取 [构图与色阶](references/art-direction.md)，按主风格打开真实样例总览与对应节点局部。标明本图开敞面、重点节点、树群、林缘、留口和草坪亮暗区，确定主次及材料差别；树木先组织群落，再分冠幅角色，草坪先做连续空间的明暗，再叠细草纹。

读取 [焦点、明暗与色彩组织](references/focus-and-color.md)，将主节点、衬托空间、明暗和颜色职责落实到目标分区；无效果参考时也要自主完成这份表达安排。以简化色块验证主次，再深化材质。已有成图平、灰或缺少重点时，先检查最终合成中的层次损失；增加树数、纹理和设施不能代替这一步。

选好风格后读取 [材质合成工序](references/material-finishing.md)，查询素材库对应风格 / 部位的完整配方。按“基底、肌理、局部明暗与校色、边缘接触、植物配景与投影、整体统一”安排实际操作；核对 Opacity、Fill、父组、剪贴、样式开关及嵌入图案。素材置入只完成其中一部分。

读取 [质感、街树节奏与最终表现](references/rendering-quality.md)，将上述职责落实为各部位的具体处理顺序。普通行道树按路段组织序列、冠幅、树色和合理留口，明确的种植图或规则树阵优先。检查树冠自身明暗、相邻材料的遮挡与接触、彩度分配、边缘软硬和最终尺寸下的细节密度；执行了工序但仍然平、灰、均质时调整方法。

读取 [样例对照与视觉验收](references/visual-review.md)，从最影响主图效果的节点选试铺，连同相邻树群、草坪和路径形成完整空间；重要水景或特殊材料未覆盖时补一小块。保存同一目标范围的基底、材质、完整合成对照，先检查本图主次和局部材质，有适用样例时辅助比较。主图的明显问题修正后再展开全图；这由执行者检查，不新增用户确认环节。

复用旧脚本前核对其功能映射、试铺范围和完成判定：取色代替功能识别、逐岛重复同一渐变、按图层组存在就勾完全部工序，都需要在本次执行中改正。每项操作记录实际作用图层和证据；操作完成与视觉通过分别记录。源 PSD 中已合并的笔刷 / 滤镜仅能据像素判断结果，不虚构原作者的操作历史。

可用 scripts/visual_recipe.py 生成三档树冠尺度计划和草坪起调参数。它不分配树位、认定树种或代替目标尺度校验。先读取 --help，输入本图确定的中型冠幅像素值；不沿用历史图的固定像素大小。

## 执行与交付

读取 [绘制流程与过程记录](references/pipeline.md)，按目标分区建立蒙版、材质与配景层。用户指定 Photoshop 时优先用其原生脚本；允许后台完成时使用适合分层交付的执行方式。实际操作 Photoshop 时再读取 [Photoshop 实施要点](references/photoshop.md)；需要界面操作时使用已安装的 computer-use skill。

所有填色受场地及功能分区约束。树冠放大后重新检查边界、通路和建筑遮挡，不能只修改缩放值。核对边缘、转角、窄绿岛和大块空白，尤其检查用户指出的遗漏位置。

原 CAD、PSD 和素材源文件保留，成果另存新版本。交付所需的分层 PSD、高清图、预览和素材使用记录；需要视频时记录实际完成的绘制步骤。20 秒视频不能用单张完成图的动画显露代替实际过程。

验收同时检查几何与蒙版、素材来源、空间与植物主次、草坪宏观明暗、材质可辨识度、边缘光影、PSD 重开及所需视频时长。按视觉验收记录本次最终导出图的观察、未解决项和实际完成度；机器检查通过或配置写了 L2 都不能代替成图验收。

技能规范、执行工具和实际成图分别说明验证状态。新增规范与通过格式检查，只证明工作方式已更新；采用新体积或合成方式时，先确认本机执行能力，再以真实试铺与最终成图证明效果。
