# 构图与色阶

本机默认表现起调值集中维护在素材库 `standards/visual-composition.json`。它们用于示意彩平的视觉组织，不代表植物实际冠幅、施工规格或源 PSD 测量。明确的种植图、规则树阵和用户要求优先。

## 空间主次与表现尺度

从目标设计标明主要节点、开敞空间、围合树群和过渡地带。决定哪里形成视线焦点、哪里保留安静背景，再分配纹理强弱、深浅和配景密度。一个连续空间可以包含多个蒙版，不能把每个闭合小区都当成需要同等强调的独立景点。

分别看主场地裁切和最终完整图幅，防止大片外围留白缩小主体后误判树木与细节。前者判断园区内部的主次，后者判断最终展示是否清楚；周边按用户范围处理。两图缺少可信尺度时，只比较视觉分量，不从相同像素宽度推断真实冠幅。

画面平、灰或缺少焦点时，用 [焦点、明暗与色彩修正](focus-and-color.md) 将上述角色落实到目标分区，并检查最终合成中的明暗与色彩贡献。鲜明风格先以简化块面检验空间重心，再深化纹理；不以统一提高饱和度代替主次。

## 树冠：三档尺度与群落节奏

- 中型冠幅 D 从目标设计尺度或本图确认的表现比例确定。自由景观示意可从小树约 0.55–0.75D、中树 0.85–1.10D、大树 1.25–1.65D 起调，数量约 30% / 50% / 20%。占比按空间调整，小范围节点不机械凑齐三档。
- 大树用于节点锚点和树群主体，中树组织林缘，小树收边、过渡与花树点缀。先定角色，再生成位置和冠幅。避免在单一窄范围均匀随机缩放，也不把三档树按固定顺序循环排满场地。
- 看群落的可见轮廓、覆盖分量与开口，不能只看单株尺寸分布。在允许自由布置的种植区，先安排主体树群及疏段，再补辅助树与林下层；不要给每个绿岛同样的树数、密度或树种循环。已有明确树位时保留设计，通过冠形、层间遮挡和色阶改善阅读。
- 一个自然树群可从一株主体配若干中、小树起调，形成局部重叠和不规则轮廓。相邻树群之间留疏段、开口、草坪口袋和视线。树群外缘不必紧贴每一段绿地边界；开敞草坪边树应有断续，避免等距围成整圈。
- 群内兼顾冠形、疏密、深浅，颜色服从主风格；花色与高亮树冠局部强调。明确的规则树阵按已有树位、规格和序列处理，不为满足自然式统计阈值破坏秩序。普通示意街树按 [路段组织方法](rendering-quality.md) 保留沿路秩序，同时形成段落、节点与单株层次，不把 formal 的窄冠幅范围应用于所有行道树。
- 比较可见树冠尺寸，排除透明画布余量和投影。多株树组不能当成一株大树。放大后检查原始像素上限；不足时换更清晰的已核验素材或调整本图表现方案，不把所有树一起压小。
- 大树放置后重新校验完整冠缘、树影及建筑、通路、文字遮挡。设计已有明确树位和冠幅时忠实保留，通过可用冠形、明暗及群落前后关系丰富表现。
- 分别检查树干允许位置、树冠允许覆盖范围和最外层场地蒙版。若目标设计允许乔木覆盖步道，其树冠与树影可跨内部种植边缘；若设计不允许则保持退让。不要为通过“整冠塞入狭窄绿岛”的算法统一压小乔木，也不能以表现需要遮挡必须保留的标注和通行信息。

自由式、大样本方案的冠幅 P90/P10 小于约 1.8，可提示尺度差异可能不明显。统计通过也不保证美感：检查局部树群和最终整图缩略图。样本很少或规则树阵不按此阈值判定。

## 草坪：大块明暗在先，细草纹在后

- 同一块较大草坪形成连贯的中间底色、开敞亮部、林缘或遮阴暗部。不同绿岛各填一种近似绿、添加颗粒噪点或树影，都不能代替裸露草坪自身的宏观层次。
- 起调时中间调约占 65%、亮部 22%、暗部 13%，随空间角色调整。亮部放在开敞活动面与视觉核心，暗部沿实际遮阴、林缘和退让空间组织，柔和过渡。
- 在主色相附近变化明度和少量饱和度。可从亮部较中间调高 5–9 L*、暗部低 8–15 L* 试起。这里是调色方向，混合模式与底图会改变结果，须看最终合成。
- 大块明暗的常见起调尺度约为 2–5 个中型冠幅，柔化约 0.4–1.2D，并受所在绿地尺度约束。避免每块草坪都有相同椭圆亮斑、硬边随机斑块或平均分布的云纹。
- 在连续空间中组织明暗场，再用分区蒙版裁切；相邻绿岛可有呼应，也允许小块草地保持安静中间调。距离边缘或树群生成的蒙版仅作草案，逐块观察是否形成重复的中心亮斑、等宽暗圈或枕状鼓包；出现时调整形状、偏移和作用范围，不只增加模糊或噪点。
- 独立保留“草坪底色 / 开敞亮部 / 林缘暗部 / 细草纹”。纹理作辅助，避免把三档底色混成统一亮绿。地形不明时只作表现层明暗，不新增等高线或虚构坡高。

检查时排除树冠、地被、建筑及投影，防止把其他物体的明暗算作草坪层次。较大连续草坪可用按冠幅尺度平滑后的 L* P90−P10 约 8 作初筛；细纹理引起的像素波动不等同于大块色阶。缩略图难辨亮、中、暗时调整覆盖与混合强度。

试铺选区、展示尺度和修正判据统一使用 [样例对照与视觉验收](visual-review.md)。数量、色值范围、素材种类和图层数只说明配置。
