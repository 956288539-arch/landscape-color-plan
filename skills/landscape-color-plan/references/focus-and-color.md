# 焦点、明暗与色彩组织

用于新图的自主表达安排，以及“画面平、灰、没有重点、饱和度不好看”的成图修正。效果参考图是可选输入。清淡、水彩、平涂或多中心设计按用户意图调整，不将高反差当作所有项目的唯一目标。仅诊断或维护 skill 时输出判断与规则；以下绘制步骤在用户要求绘制时执行。

## 自主确定表达方向

先区分目标 CAD / 设计资料与效果参考：前者提供本次几何与功能，后者可能没有，也可能只表达局部喜好。不把缺少效果参考当作缺少目标设计，不要求用户补参考才能继续。

| 输入情况 | 如何决定表达 | 如何验收 |
| --- | --- | --- |
| 用户有明确且适用的效果目标 | 提取其主次、色彩、植物和光影关系，结合目标设计落地 | 独立视觉检查，加上适用表现与参考的差距检查 |
| 参考不准确、混合多种风格或只表达大致意向 | 结合用户文字判断其想要的气质；选择相容特点，舍弃不同功能、视角、几何或尺度造成的不适用部分。记录本次解释，继续试铺 | 按所选特点与本图完整性检查，不追求逐像素接近或拼接各图布局 |
| 没有效果参考 | 从场地类型、空间结构和展示用途形成表达方案；按主风格选材，自主确定主次、色样、植物概括方式与光影强弱 | 按空间、明暗、色彩、材料和输出可读性检查，不编造用户参考或相似度结论 |

无参考时，可从这些方向判断：城市活动公园强调节点与开敞面的对比，局部用鲜明色；住宅强调安静连续的绿地、入口和会客节点；乡村强调地形与自然植被的连续性，控制人工强调色；曲线景观强调流线、草地与水岸的衔接。它们是起点，仍由本图功能和用户用途决定。

将表达方案写成几句可执行判断，例如“已有活动节点为主，水景为次；林缘深绿衬托开敞草坪，浅色路径保持连续；鲜明色集中于活动面，外围按约定灰阶处理”。再落实到分区与色样表。没有参考也不能直接对所有蒙版套同一材质；有参考也不能省略这份设计判断。常规风格选择由执行者完成，局部试铺自行复核，不新增用户审批。

表达方向还要适合交付尺度：整幅总图先看块面、路径和树群，小比例细纹应收敛；节点大样再加强材料和接触细节。用于设计校核时优先线稿与边界，用于展示时在既定范围内加强空间和色彩。用途未说明时，先以清楚、适度鲜明的专业总图为起点，不自动套低饱和滤镜，也不假定需要夸张体量。

## 先判断差在哪里

先按本图表达方案检查画面。有明确效果参考时比较适用特点，库内样例用于补充材质与工艺；记录可以迁移的表现和不能移植的设计内容。分别看完整图幅和主场地，有对照时使用相近展示宽度。不用整图平均饱和度衡量彩色园区；大片外围留白会掩盖园内差异。

| 观察 | 更可能缺少的关系 | 优先修正 |
| --- | --- | --- |
| 园区有颜色，内部却没有明确重点 | 焦点与次要区域的强弱分配 | 在目标已有节点中确定重点，调整邻接树群、留白、局部反差与强调色 |
| 绿地鲜绿，仍像平面剪纸 | 大块中暗调、冠层自身明暗和接触关系 | 先建立连续的树群暗部、开敞亮面与中间过渡，再检查投影；不先把草坪继续调艳 |
| 粉色、绿色都发灰，阴影也很淡 | 最终调色或透明度压缩了色阶，也可能是原选色过于灰浊 | 查作用范围与旧调整层；按材料分开校色，再决定是否增强饱和度 |
| 放大后细节很多，缩小后仍空、碎 | 细纹理的分量高于空间块面 | 降低叶片、草纹和接缝的噪点感，保留在交付尺寸可读的树群轮廓与材质大面 |

这些是待验证的原因。没有读到实际图层或脚本时，只描述画面症状；不能把某个灰蒙层、错误混合模式或具体滤镜当作已查明事实。

## 把主次落实到场地

填色计划中用一张简短表说明“分区 ID / 设计功能 / 视觉角色 / 明暗与颜色动作”。单一公园可从一个主节点、少量次节点和安静过渡空间起调；已有多中心结构时沿用设计。指定重点要有空间依据，不能只选面积最大的色块，也不能为获得焦点新增建筑或球场。

- **主节点**：安排可读的材质差别、适量强调色和邻接亮暗对比。最强颜色不必覆盖整个节点；局部深色树群衬托亮面，也能形成焦点。
- **次节点**：保留功能和材料识别，减少与主节点重复的高彩度面积、同强度描边或密集细节。颜色由设计指定时，通过邻接背景和明暗组织分主次。
- **开敞面与连接空间**：保持连续中间调、适度亮部和清楚的通行关系。允许安静草地存在，避免每块绿岛都做成独立亮斑。
- **围合与过渡树群**：用重叠冠层、深绿林下与实际受影形成有分量的暗部，同时保留入口和视线。不能沿所有边界均匀加黑边或把阴影连成无依据的大黑块。

用户允许改图时，先在同一目标蒙版中试验简化块面：浅色路径、草地中间调、开敞亮部、深色树群、重点节点。暂时降低细纹理干扰，同时看彩色和灰度。尚未加细节就应能读出空间重心；否则先改块面和局部对比。已有树位、路径、轮廓保持目标依据。

## 色彩按职责组织

按本图表达方案选择色相、明度、彩度及所占分量；参考存在时可从其相应材料区域校准，没有参考时结合材料常识、风格配方和下表的职责关系自主配色。按本图材料维护一组可调整色样，不直接套全图滤镜。源 PSD 色值与不透明度用于理解来源，最终取值以目标合成为准。

| 职责 | 鲜明公园表现中的常见关系 | 防止的失误 |
| --- | --- | --- |
| 草坪 | 连贯中绿为主体，开敞处偏亮黄绿，林缘适度深绿；亮、中、暗仍属于同一草地系统 | 全场统一荧光绿，或每个绿岛套同一中心渐变 |
| 树冠与林下 | 受光冠面、主体叶色和背光面可区分；深色集中成群，局部暖黄绿点亮 | 只靠叶片碎点表现深浅；整体降低透明度后树冠透底、体积消失 |
| 主节点 | 在已确认材质和配色内保留干净主色、少量浅色和深色对照；强调色落在明确分区 | 将所有嵌套色块都加饱和，或给平地添加屋面厚度来制造反差 |
| 水体 | 蓝或蓝绿主体、较深水色与有限反光形成冷暖对照，岸型决定收边 | 全池同一蓝色，或以宽白圈代替岸边工艺 |
| 铺装与背景 | 浅中性色托出植被和节点；必要线稿有足够灰阶 | 大面积发白导致材料消失，或为了统一而让彩色主体一起褪色 |

“更鲜明”需要同时控制彩度、明暗跨度、冷暖和颜色面积。只提高饱和度不会补出空间深度。优先检查主节点与邻接绿地，分别校正草地、树冠、活动面和水体；最亮与最暗只承担局部职责。高饱和色过多时，减少竞争区域的表现强度，而非把全图一起漂白。白色建筑也能成为重点，焦点不等于最高饱和度。

## 复用成图时，检查最终合成

先保留当前状态，围绕出现问题的部位列出实际起作用的底色、明暗层、纹理、调整层、父组、剪贴和蒙版。已有局部与全局调色都要核对可见状态与覆盖范围，不能因为脚本早期设置过参数就认定最后仍然有效。

按疑点在检查副本或可恢复状态中，分别查看“关闭最后调色”“关闭细纹理”“仅查看宏观明暗贡献”的前后差别。恢复状态后再决定修正方式，避免一次关闭所有因素而失去定位依据：

- 关闭末级调色后层次恢复：先调整这一级的范围或参数，不在下层继续叠更艳的颜色抵消它。
- 开关宏观明暗层几乎无变化：查是否被上层覆盖、父组淡化、蒙版错位或细纹理压平。填了深色、写了高不透明度，不等于最终出现足够分量的暗部。
- 单株树冠清楚、树群缩图仍碎：查素材的概括程度、群落连贯轮廓和冠层明暗，不能仅凭树数与冠幅分布认定通过。
- PSD 内正确而导出图明显变淡：再核对实际色彩配置、转换与导出方式；不无证据归因于显示器或色彩空间。

不直接相乘 Fill、Opacity 与父组数值推断完整效果。纹理与样式的贡献以最终合成判断；阴影的几何依据、光向和受影面仍按 [体积与光影](volume-and-lighting.md) 执行。

## 有顺序地修正并验收

优先修正主次与大块明暗，其次按材料调整色彩，再处理树冠塑形、接触与投影，最后补肌理、花境、家具和人物。每步都在同一主节点及邻接空间比较；后续材质或整体调色若抹掉已建立的层次，回到造成问题的操作修正。

按 [视觉验收](visual-review.md) 记录以下实际观察，而非只记执行了哪些命令：

- **彩色缩图**：首先读到哪里，靠什么突出；其它节点是否与其争抢。
- **灰度缩图**：树群、开敞面、路径和关键对象是否仍有成块的深浅关系。彩色有效但灰度完全均质时，单独标出明暗问题；某个颜色焦点变弱不等于整图失败。
- **最终合成**：主节点、草地与树群是否实现本图安排的色彩职责，局部是否发灰、过艳或互相争抢；有参考时另外说明适用表现仍有差距的位置。
- **100% 局部**：再确认肌理、透明边缘、受光、落影和岸线没有因增强反差而破坏。

可以用主场地或同类材料蒙版内的明度、彩度分布辅助诊断，注明裁切、遮罩与色彩空间。它们不自动决定美感，不设所有公园通用的饱和度合格线，也不以与参考直方图相似代替空间判断。
