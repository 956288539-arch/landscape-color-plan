# 按部位完成材质合成

在选好主风格后读取本库 `standards/四套PSD分层工艺拆解.md` 对应风格一节和 `standards/material-workflows.json` 对应部位。可用 `tools/materials.py --style park --role grass --workflow --json` 取得该部位的基础工序、风格适配与源图层依据。不以素材已放置作为该部位完成。

## 先识别素材在合成中的职责

区分底层形状、细纹理、大块明暗、岸边 / 收边、配景、样式资源和全局调色。裁切小样可能只保存某一层的像素；它的最终外观可能依赖下方底色、剪贴基底、父组、填充不透明度、图层效果及后续调整。

读取索引 `source_fill_opacity_pct`、`source_opacity_pct`、`source_parent_opacities` 与 `source_composition`。按源 ID 在完整事实文件中查找剪贴基底、样式总开关、单项效果开关、图案资源、颜色、比例、位置和调整层。仅有 DropShadow 类型和距离不能完整还原一个材质。

源图经验：P 用柔化蒙版控制纹理显露，配合地形叠加及整组调色；R 的草地明暗部分已存入像素，屋面 / 地面依赖样式，建筑影单列；M 的双草纹、曲线与饱和度同属一个剪贴基底，之后还有上部调色；U 的草坪和铺地大量使用 Fill，花境又有基底图案与上层花色。

## 建立本图的操作栈

1. **底色与覆盖**：以目标几何建立底层、孔洞和蒙版，先组织大块色阶。取样纹理不决定区域外形。
2. **表面肌理**：选择实际纹理尺度和方向，分开主纹理与变化纹理；检查重复、镜像痕迹和细节频率。
3. **局部塑形**：在连续空间中安排亮部、暗部和过渡，以独立明暗层或调整层 + 蒙版实现。已画进源像素的渐变只作为观察证据；按新空间重建其作用，不复制原场地形状。
4. **边缘和接触**：依据部位选择岸内暗边、台阶 / 构件投影、铺装收边、林缘压暗。内阴影不等于把每块绿地均匀圈黑，外投影也不能代替所有边缘处理。
5. **植物与节点**：草地、低植被、花色、乔木分别组织；配景按功能布置，对象的接触影与外投影分工，保持开口、视线、树群大小与疏密。
6. **局部与整体校色**：先校正部位的冷暖 / 明度 / 饱和度，再在所需范围统一画面。保持浅路、深植被、清楚主体及可读线稿；不能用整图白蒙层掩盖局部问题。最终调色后重看先前建立的空间主次与明暗；出现平、灰、层次消失时按 [最终合成复核](focus-and-color.md) 定位作用层，避免多轮校色相互抵消。

这是职责清单，不要求每块地固定六层。已有像素能承担某项职责时核验后复用；空间不适用的操作记录原因。新图缺少宏观明暗时，不能仅因素材像素有颗粒或已有一个投影，就把该项记为完成。

## 材料应有可辨识的结果

按目标功能选择下列处理。示例用于判断表现差别，不授予新增设施、台阶或地形的权限。

| 部位 | 应能读出的信息 | 重点操作 |
| --- | --- | --- |
| 主路、支路与活动铺地 | 行走方向、停留面和材料衔接；设计相同材料时保持一致 | 核对铺装纹理的实际尺度、拼缝方向与强弱，沿既有边界组织收边。大面积细粒噪声不能代替石材拼接或木板方向 |
| 花境与低植被 | 深色植被背景、粗细植物、局部花色及与乔木的遮挡 | 分区布置底层和花色，用蒙版打破均匀覆盖，保留透底与自然冠缘；整块粉色平涂不自动表示花境，粉色本身并非禁用色 |
| 建筑、构筑物与彩色活动节点 | 能辨认屋面、设施或地面，而非仅有套叠色块 | 从目标资料确认对象。屋面表达已有轮廓、细部及体积；活动地面表达已有材料分区、接缝或标线。未确认功能时保留待核状态 |
| 水面与水岸 | 水陆接触、深浅或反光，以及岸边构件关系 | 水底和细水纹分工，岸内接触暗部与压顶亮部按实际岸型变化；不将整圈等宽内阴影当全部水岸工艺，喷泉、平台等仅在目标具有时绘制 |
| 乔木与构件光影 | 树冠自身层次、树下接触暗部和落在地面上的方向性投影 | 保持统一光向，按对象高度与表现尺度区分阴影偏移和软硬，检查叠压顺序、烘焙影和父组透明度。清淡风格仍要核对局部明暗，用户明确无投影风格时遵从 |

最后按主风格校正各部位，优先处理主节点与周边的明度、冷暖和饱和度关系。不要用整组降低透明度使树冠、铺装、岸线一起变淡，也不要为了增加细节给所有区域使用同等强度。

若目标要求明确的曲面、高差或构件厚度，按 [体积、地形与统一光影](volume-and-lighting.md) 为对应对象选择绘制或局部简模方式。材质合成仍需核对顶面、侧面、接触暗部和投影各自职责；源素材的一个外阴影不能承担完整体积塑形。

## 不透明度、样式与资源

- 整体 Opacity、Fill、父组 Opacity、素材像素 alpha 分别记录。Fill 通常控制层像素而保留样式贡献，Opacity 还作用于样式；带样式时不要把二者直接相乘后只设一个 Opacity。特殊混合模式还需实际渲染校验。
- 同时保留效果总开关与各效果 enabled。未启用的源效果不自动开启；如果为本图重新设计投影，记录为本图处理，不声称恢复了源状态。
- PatternOverlay 必须解析真实图案资源、模式、比例、透明度和相位。优先从源 PSD 转移原生样式及嵌入图案到临时文档，再作用于目标形状。核对目标保存后图案仍可渲染。只拿到 UUID 或没有样式的 PNG 不能标记为完整恢复。
- 原始蒙版用于理解表现作用，新图蒙版从目标几何重新建立。模糊或阴影后重新检查外边界和内部水陆、铺地、建筑关系。
- 原图含建筑、地形或其他场地的合成层只供判断表现，不能成为新目标底材。纹理 / 风格可以复用，源项目几何和标签不能随之置入。

## 完成判定与交付记录

为主要部位保存 `zone_id / workflow_id / operation_id / target_layer_ids / mask_ids / actual_parameters / status / frame_path`。状态使用 done 或 not_applicable；后一项附具体空间理由，未执行保留 pending。已完成的纹理、色阶、边缘、调色等操作都可进入真实过程帧。

逐项保存 `operation_evidence`，说明哪些实际图层、蒙版和参数承担该操作，指向对应阶段图或图层核验。不得将父组下的全部图层与同一份通用参数复制给所有操作后统一标 done。一个图层可承担多项职责，但需分别说明证据。已确认不具备某功能可记 not_applicable；功能尚未识别、未完成或素材缺失保留 pending。

局部试铺至少比较基底阶段、材质阶段与完整合成，检查补充处理的可见贡献。使用临时副本开关图层，不更改源 PSD。分析用对照图标注为对照实验，不能混入交付过程视频冒充绘制历史。

done 仅表示该操作有执行证据。按 [视觉验收](visual-review.md) 另存视觉观察与 pass / revise / not_applicable；操作齐全但表现薄弱时仍需调整。重开 PSD 验证填充、样式、图案及剪贴依赖，技术核验与视觉验收共同决定实际完成度。
