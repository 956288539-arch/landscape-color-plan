# 本机 Photoshop 实施要点

以下行为在本机 Photoshop 2024 / 25.0 验证过，适配其他版本先做小型能力检查。后台任务可通过 API 完成，不依赖鼠标录制。

## API 与坐标

Windows 可用 win32com.client.gencache.EnsureDispatch('Photoshop.Application')，完整 JSX 字符串传给 DoJavaScript。明确传入源文件、输出目录、缓存和计划，不依赖 $.fileName 或历史绝对路径。项目 work/*recolor* 为单次案例；执行前需针对当前任务重构参数和恢复条件。

本机 PathPointInfo 数值坐标按点单位解释，画布 px 输入路径需乘 72 / document.resolution。先建 100 × 100 px 校验框并读取选区边界验证。移动与变换显式用 UnitValue(value, 'px')。

建组优先 parent.layerSets.add()。本机曾出现 LayerSet 向另一个组 move(..., INSIDE) 报非法参数，而 ArtLayer 可移动。可隐藏旧组并在目标父组中新建层级；总组在线稿下，场地与分区蒙版分别管理。

## 材质、智能对象及投影

源纹理不默认无缝。可在 Photoshop 做 2×2 镜像派生并记录母素材与参数；这只使对应边连续，不保证没有明显重复或对称斑块，必须实铺查看。

树冠、坐凳和人物优先用智能对象，配本图统一方向的原生投影。源 PNG 通常未烘焙总体透明度、剪贴和图层效果，应读索引后重建；已有烘焙阴影则避免重复加影和任意旋转。

分别设置 ArtLayer.opacity 和 fillOpacity；前者还影响图层效果，后者不能被一个整体透明度取代。父组透明度也需读取。M / U 源 PSD 尤其多见 Fill 小于 100%，漏读会导致草纹过强、树冠过实。

图层样式包含内阴影、颜色叠加、图案叠加、描边等，不能只恢复外投影。PatternOverlay 的名称与 ID 不足以恢复外观；连同源 PSD 内嵌图案资源转移并检查模式、比例、相位与保存后渲染。已有关闭的样式不自动启用。

本机在临时副本中已验证 disableLayerStyle 动作可关闭当前层样式，layerFXVisible 可读取实际开关。用于对照审阅时每次从同一原始状态开始，关闭副本且不保存源文件；这种对照不属于作者绘制历史。

Plc / place 动作可在置入时传缩放、角度，减少反复复制、栅格化和变换。为避免 DPI 引起额外比例变化，可把 PNG 副本设为文档 DPI，使用 ResampleMethod.NONE 保持像素尺寸。核对可见 RGBA 与原素材一致，记录副本哈希，原素材不覆盖；透明像素隐藏 RGB 变化不影响显示。

置入后读取未含效果的可见边界，校验冠幅和中心，不假定默认放在画布中心。透明边距要从冠幅计算中排除。调整尺寸后重新检查边界、通路和遮挡；角度服从素材原光向。

投影用 Lefx / DrSh 配置 multiply、颜色、透明度、光向、距离和柔化，保持可编辑。画布右为 +x、下为 +y 时，期望偏移 dx、dy 可从距离 hypot(dx,dy)、光源角 atan2(dy,-dx) 起调，并用单株核验。图层整体透明度影响效果，补偿后要读取实际值并目视，注意整数舍入。

确需栅格投影时，已验证 selection.fill(color, NORMAL, 100, true) 的保留透明度方式可用。透明像素锁定与不保留透明度的填充组合在本机曾报“填充参数无效”。

## 表现与运行

草坪分别创建中间底色、开敞亮部、林缘暗部、细草纹，先设计大块明暗蒙版，再叠材质。云彩或噪点只作辅助。模糊、位移和发光后再查分区边缘；水纹过强或出现重复亮带时降低对比、柔化并重新裁切。

保存并在 finally 恢复本次改动的单位、对话框模式及前 / 背景色。减少重复置入、无用变换、整图存档和 UI 刷新，按实际步骤保存帧，大阶段或适当批次保存 PSD。suspendHistory 可合并一项逻辑操作，但先验证阶段图正常。本机 app.refresh() 曾阻塞执行，不作进度心跳。

长脚本忙碌时用文件日志读进度，不堆积多个 COM 调用或反复争抢窗口；步骤边界处理停止和恢复。界面操作遵循 computer-use skill。

输出后用 Photoshop 重开 PSD，核对嵌入数据、投影、路径、色彩配置与导出像素。树冠尺度及草坪大块明暗在最终缩略图应可辨，不能只凭图层数判断完成。
