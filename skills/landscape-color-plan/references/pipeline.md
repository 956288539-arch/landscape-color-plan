# 绘制流程与过程记录

## 输入、几何与素材

从当前任务指定的源 CAD / PSD 开始，确定本次目标目录和新版本名。历史文件名、像素范围、树数及分区编号不可直接沿用。

效果参考可选。先按 [焦点、明暗与色彩组织](focus-and-color.md) 形成适合目标功能和展示用途的表达安排，明确参考、大致意向和无参考都可以继续。有成图时检查继承的局部 / 全局校色及父组作用，新图先用简化块面验证主次，再展开材质。

保存可逆 CAD→画布仿射变换、画布尺寸、DPI、单位依据、场地及分区 ID。CAD 单位未定时如实记录；DPI 不提供模型尺寸。已有蒙版要核对是否属于本次最新几何；检查曲线首尾、孔洞、碎片、自交和遗漏。

按索引选择 approved=true 的 texture / symbol，读取源哈希、像素、透明度、混合方式、symbol_units、baked_shadow、source_effects。reference 中的建筑、水池、道路及文字不进入目标几何。跨库使用按配方记录理由。

按部位查询 material-workflows.json，展开到本图的 zone_id、operation_id、图层、蒙版、实际参数与完成状态。读取完整合成依赖，分别处理 Fill / Opacity、父组、剪贴基底、样式总开关与图案资源；方法见 [材质合成工序](material-finishing.md)。

为关键分区补充 function / material / evidence / certainty，依据目标图层语义、标注及设计资料判断；NODE 等泛称或参考色样不作为唯一依据。certainty 未确定时不执行依赖该功能的设施或材质深化，也不记 not_applicable。先完成其他明确部分，无法核实的关键项集中说明。

复用历史脚本时，核对其场地与树冠蒙版是否混用、冠幅是否仍硬编码、宏观明暗是否逐岛复制、试铺是否覆盖本次主节点，以及核验是否把父组存在等同全部工序完成。修正本次脚本或实施方式后再运行。按 [视觉验收](visual-review.md) 完成关键局部与样例对照后展开全图，各分区按空间角色适配参数。

需要体积表达时读取 [体积、地形与统一光影](volume-and-lighting.md)，记录对象高度依据和所选实施方式。使用局部模型时保留模型版本、匹配 CAD 的视图/坐标、画布投影方向、接收面蒙版与实际输出层；配准并检查混合边界后再用于整图。

## 图层与实际步骤

一般从线稿与蒙版，推进到铺地、草坪大块色阶、细纹理、地被花境、屋面 / 水岸、树冠投影、设施活动配景，最后统一线稿和整体色调。按实际遮挡调整层次，仅表现方案已有或本次授权的功能内容。

每次成功完成一项可见操作，再保存过程帧和日志。操作可以是一处草坪亮部、一组相邻地被、一株树冠及其投影、一项配景。未完成的错误状态不充当成功步骤。

分区颜色与肌理裁在对应蒙版内，整套彩色内容另受场地蒙版限制。原参考组隐藏时不与新版同时显示。尺寸、标签、轮廓和入口保持清楚。

## 中断恢复

日志记录 run_id、step_id、操作类别、mask_id、asset_id、源和参数指纹、过程帧路径与完成状态；保存点记录 PSD 及最后完成步骤。派生缓存依源哈希和参数识别，不能只依素材 ID 复用。

批量脚本在步骤边界检查本任务的停止标记，保存新版本和进度后退出。恢复时核对源、几何与设置指纹，对应 PSD 实际图层及效果；仅凭帧数不能判断已完成。重做前只清理本任务标记的未完成对象，避免重复叠加。

## 20 秒视频

收集成功步骤的实际画布图像，固定视图，按 step_id 排序。用帧数 / 帧率控制时长，例如 20 秒 × 30 fps = 600 帧，预留少量开头及完成画面停留。

承诺逐步记录的每个阶段至少出现一帧。步骤多于可用帧数时先评估提高帧率；仍放不下时明确调整分组粒度或与用户协商时长，不静默丢弃步骤后声称逐项展示。编码、报错和文件整理无需进入绘制视频。

核验时长、帧数、完整解码和首 / 中 / 尾画面。阶段图合成在交付说明中写清楚，不称鼠标桌面录屏；单张完成图的动画显露不属于实际填色过程。

## 交付验收

- 整图和 100% 局部核对树冠尺度、树群节奏、草坪大块明暗，以及边角和空白遗漏。
- 检查场地外溢色，按实际抗锯齿和线宽记录容差；同时检查内部功能分区。
- 贴图接缝比较预乘 alpha 的 RGB 及 alpha，透明像素隐藏 RGB 不算可见接缝；大面积重复和明暗带仍需目视。
- 重开 PSD，检查尺寸、DPI、色彩配置、路径、分层、智能对象和效果。若重算效果有微小舍入差异，如实记录容差，不能强称逐像素相同。
- 使用记录包含素材 ID、源和派生哈希、派生规则、位置、冠幅角色、缩放、透明度、蒙版、光向、草坪明暗配置及实际图层核验值。
- 核对部位工序的完成状态、阶段对照、局部塑形、边缘与调色的实际贡献；PNG 已放置不能代替完整部位验收。保存填充不透明度、图案资源及效果开关。
- 操作逐项对应 operation_evidence，视觉观察另存 visual_review；检查最终图像的园内主次、明暗分量与色彩关系，不以新补细节代替整体复查。用户效果参考存在时检查其适用特点，无参考时依据本图表达安排验收；不通过树数、父组名或声明的 quality_level 自动授予 L2。主要问题未解决时记录实际完成度和剩余项。

按需求交付新版本分层 PSD、高清图、预览、使用记录和视频。保留源文件，完成度以实际空间和视觉效果核对。
