# 质感、街树节奏与最终表现

用于素材已经填上，但画面仍平、散、灰、均质的情况，也用于新图确定具体合成方法。效果好坏由最终图像中的材质、光影、节奏和主次共同决定；参考图有无，不改变这些基本要求。先按目标对象处理，以下方法不授予新增建筑、设施或地形的权限。

## 选素材时就按最终效果判断

在本图预定冠幅与最终展示尺寸下试用素材，检查它承担的是主体、辅助还是背景。候选素材要连同地面和投影一起看：孤立 PNG 清晰，不保证组合后好看；放大原像素也不补出真实细节。

例如库内 U-T03 有密集叶片细节，U-REF03 的完整效果还依靠树影、开敞草地、木平台和人物尺度。调用 U-T03 之后仅改尺寸与透明度，会丢掉原组合的重要关系。U-T04 的低对比度适合部分背景街树，不能成为所有路段的唯一表现。源参数是证据，目标中的位置与角色决定最终起调。

若目标需要概括的体积树冠，而候选树缩图后只有碎叶噪点，换候选素材或制作可追溯的明暗派生版本。保留冠形与有效像素，按实际冠层结构处理受光和背光；不能用无差别磨皮、锐化、加影或增加数量代替素材适配。

## 行道树：沿路有秩序，路段之间有变化

区分三个层级：道路走向决定序列，路段和空间节点决定疏密节奏，单株表现提供小幅自然差异。规则树阵、仪式性林荫道或工程种植图明确要求统一时保持设计；一般示意街树不自动套用“全场等距、同冠幅、同树色”的模式。

先按目标划分路段，记录 `segment_id / 树位依据 / 序列类型 / 主要冠形 / 冠幅区间 / 留口理由 / 明暗角色`。不要把整块用地向内偏移一圈就视为有效种植线；应检查道路、人行空间、入口、建筑退让及现有树位。尺寸不明时标明示意，不把像素间距写成工程米数。

| 路段条件 | 布置与表现方法 |
| --- | --- |
| 连续人行路段 | 保持可读的排列轴线和相对稳定的基准间距；在设计允许下让冠幅、冠形和树龄感缓慢变化，避免每株随机跳色跳尺度 |
| 入口、过街口和转角 | 依据实际通行、转弯和视线位置留口或退让；缺口有空间理由，不用固定“每隔 N 株删一棵”制造变化 |
| 已有停留或入口节点 | 在允许布置的种植范围内局部加强树群、成对点树或较完整树冠，与邻接的连续树列形成节奏；不挡主入口与关键标注 |
| 接公园林缘的路段 | 街树序列与园内群落衔接，允许前后层次及局部冠层重叠，避免道路两侧都成为等宽珠链 |
| 远景、背景或窄界面 | 简化纹理、控制反差与覆盖分量；保留边缘及必要接触，不把所有背景树降成相同透明圆点 |

没有明确冠幅设计时，普通街树可从同一路段约 0.85–1.15 倍基准可见冠幅试起，变化成段且与节点角色相关。此区间仅是表现起点，不能套在已确定的规格上；街树不要求满足自然树群 P90/P10 阈值。避免固定大中小循环或完全独立随机缩放。

颜色变化先安排路段基调和局部暖色点景，再调整单株。不要一棵黄、一棵绿交替排满，也不要只复制同一树冠后旋转：带方向性明暗的素材旋转会破坏统一受光。场内与场外、前景与背景的反差可以不同，仍需保持图面整体联系。

## 材质合成要落实到可见关系

| 部位 | 具体处理顺序 | 达到的质感与常见失效 |
| --- | --- | --- |
| 乔木 | 先确定冠层轮廓和主体叶色；利用原素材已有明暗，在需要的位置补冠面亮部与背光；组织树群叠压与林下暗部；按统一光向处理实际受影面上的树影；最后保留适量叶片细节 | 冠面、背光、地面投影能分别读出。外投影不能替代树冠自身塑形；阴影不能全部锁在狭窄绿地里，或与树冠一起被透明度压到消失 |
| 草坪 | 连续中间底色上安排开敞亮区与林缘暗区；再加中尺度、低强度的自然色差；最后叠细草纹，检查上层纹理没有盖掉宏观变化 | 远看连贯、近看有草质。三种绿色不等于三层空间；随机云纹、逐岛亮斑、满幅高频噪声都不代替地面层次 |
| 灌木与花境 | 先形成有厚薄与断续的植被底团；叠粗细不同的植物簇；少量花色成组聚散；在真实交接处补接触暗部，允许乔木遮挡部分下层 | 前后覆盖和疏密可读。整池填同一花纹、每块给相同花量，仍会像平面贴纸；低矮植物不要使用乔木影长 |
| 铺装与木面 | 确定真实材料分区；按路径或构件组织拼接、板缝与纹理方向；做适度块材色差；按相邻对象处理受影和必要收边 | 大面干净，材料方向可辨。用均匀颗粒表示所有硬地会失去材质；分缝过粗会在缩图形成网格噪声，须按最终尺寸回调 |
| 活动地面 | 保留已确认的材质和图案几何；安排主色、辅助色与少量强调色；按原设计表达拼缝或标线；结合实际邻接树影、设施和边界收口 | 图案可读、色彩有重心，仍然像地面。不要给每片彩色轮廓加浮雕与外阴影，或增加无依据的褶皱、围墙和屋顶体量 |
| 水面与岸边 | 先定水色主体、适度深浅和反光区域；用细水纹支持大面；依据实际岸型分别处理水内接触、岸边材料与受光；有构件时再处理遮挡和投影 | 水色有清透与深浅，岸线不悬浮。反光不铺满全池，深浅不反推成真实水深；不能以等宽白圈加蓝色渐变替代全部岸边工艺 |

同一空间的相邻材料互相影响：树影落在步道与草地时，应保留各自底材；树群前缘与灌木有遮挡，开敞草坪仍有空处；水体靠岸与中央的关系服从岸型。按目标允许的冠层覆盖和受影面建立蒙版，不把每个对象彻底隔离后各自填色。

## 饱和度和边缘一起控制

先按本图焦点安排颜色面积，再分材料校正明度、彩度与冷暖。主节点保留干净而集中的强调色，草地与树冠形成相邻但可区分的绿系，水面提供适量冷色，铺装与背景提供中性衬托。具体颜色来自用户要求或本图自主配色，不要求照搬样例的粉、蓝、橙。

“干净”不是消除全部变化：避免多个灰浊色在同一节点等量竞争，也避免为了提亮叠白后把主色冲淡。树群需要足够的中暗调，草地亮部不必一直提高饱和度；深色也不要一起压到无叶色、无材料。调整后同时看色彩缩图和最终合成，主图中所有颜色一起变艳或一起变灰时重新分配作用范围。

边缘按材质分工：硬质构件清楚，草缘适度柔和，植物冠缘有自然破碎，水岸按实际构造收口。重点邻接处可以有更明确的接触对比，次要处减弱线稿和细节；不要全部描同样粗的白边 / 黑边，也不要整体模糊使材料一起失去边界。

## 从参考中迁移方法

有参考时，除色相与树数，还检查：树群覆盖分量、连续树列与间断的节奏、开敞与密植的比例、颜色集中位置、受光与背光、投影软硬、硬地和绿地的边缘、人物与设施的聚散、外围灰阶以及最终缩图的细节密度。逐项说明可迁移到哪个目标部位；不同功能、几何与已确认树位优先保留本图。

无参考时，上述关系仍由执行者自主安排。整体丰富度来自有组织的差别，不按素材数量、噪点密度或图层数量追求“填满”。

## 让试铺验证处理方法

主节点试铺同时覆盖相邻树群、草坪、硬地及本图关键边缘。包含街树的项目另看一段连续路段与一个实际留口 / 节点，不能只检验孤立树 PNG。保存基底、材质、完整合成的实际变化，并在最终图幅中检查新增处理是否仍可见。

同一缺陷在新一轮仍明显时，回到造成问题的环节换方法：树冠持续碎就检查素材与冠层塑形；草地持续平就调整宏观作用范围和合成顺序；街树持续像珠链就重查路段组织；材料持续灰就定位校色与透明度；边缘持续漂浮就重建接触和受影。不要以重复加材质、加树或生成更多检查文件结束修正。

这些操作是否实施，按 [材质工序](material-finishing.md) 留证；是否好看且清楚，按 [视觉验收](visual-review.md) 查看最终图像。仍然均质、平淡或色彩混浊时保留需修正状态，不能用操作已完成代替结果。
