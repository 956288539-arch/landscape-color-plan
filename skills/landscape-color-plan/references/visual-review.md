# 样例对照与视觉验收

用于开始试铺、批量展开前、最终导出后，以及用户指出成图问题时。评价本次目标与所选表达方向；效果参考可选，规则树阵、平涂示意或明确无阴影风格按用户选择判断，不套用自然公园的全部表现。按 [焦点、明暗与色彩组织](focus-and-color.md) 区分明确参考、大致意向和无参考三种情况，均以本图独立视觉检查为基础。

参考强调体积或地形时，增加 [体积与光影验收](volume-and-lighting.md) 中的对象依据、受影关系、植物表现和渲染配准检查。能借鉴的表现与新增设计内容分开判断，不因参考出现某构筑物就认定目标也要增加它。

## 选对照和试铺范围

用户明确指定效果目标时，先打开该图并记录适用于本图的特点，不能只查看库内样例便声称达到用户效果。参考仅表达大致意向时，记录实际采用的特点，不把全部画面当作必须复刻的标准。没有效果参考时，自主选择表达方案，不要求用户补图，也不编造参考匹配结论。

从 local-library.json 定位素材库，打开可用的主风格总览及对应 recipes.reference，辅助判断材质、树冠和工艺；一般一个总览与一至两个相关节点足够。需要分析特殊部位时再展开对应源 PSD。库内参考条目不作为可铺入目标图的素材，库内工艺可用也不能代替本图的构图判断。

先看目标完整图，再看主场地裁切，指出最影响最终画面的具体区域。试铺覆盖主节点及相邻树群、草坪、路径的关系；重要水景或另一种特殊材料未覆盖时补充小样。边角检查用于验证边界，不能代替主节点的表现试验。

对同一目标范围保留基底、材质、完整合成的阶段图。与样例比较时：

- **最终图幅与主场地缩略图**：分别检查展示主次与园区内部组织。将场地裁切为接近的展示宽度，说明这是视觉比较；真实比例依据 CAD 或已知尺寸，不以两图像素等宽推断树木同尺度。
- **100% 局部**：查看树冠、铺装、岸边、接触影和透明边缘。纹理只在放大后出现、缩图完全失去功能区别时，先调整大块材料与明暗关系。
- 比较目标里确实存在的对象，不要求每块地复现样例的设施数量或细节密度。画面平、灰、没有重点，或本次强调立体感时，增加主场地灰度缩图和相关图层贡献检查，方法见焦点与色彩指南。记录真实观察；检查图不替换交付图，也不是实际绘制步骤。

## 用画面决定是否继续

每项结论写出位置和观察，使用 pass / revise / not_applicable。后者说明目标或用户风格依据；尚未识别功能或尚未检查不能记为不适用。

| 判据 | 可接受的视觉证据 | 需要修正的表现与优先动作 |
| --- | --- | --- |
| 空间主次 | 说明缩图首先读到的具体节点及其突出原因，园区内部重点、次要节点与过渡有强弱 | 只能说明“彩色园区比灰色周边突出”，不能证明园内有主次；所有绿岛和节点同强时重排表现重心，不擅自合并绿地或改路 |
| 明暗分量 | 按本图风格，树群、开敞面、路径和关键对象形成可读的大块深浅，暗部位置与对象关系相符 | 图层有深色但最终仅剩零碎暗点，或放大有影、缩图全平：检查实际合成与暗部覆盖，先修主场地块面，不把每块地圈黑 |
| 色彩关系 | 明度、彩度、冷暖及颜色面积服务本图角色；重点清楚、次要区域衬托，材料没有一起发灰或过艳 | 所有节点同艳、草坪统一亮绿，或末级校色抹掉区分：分材料和分区调整，并复查最终合成；不以提高全图饱和度或泛称“统一协调”作为通过证据 |
| 树群与尺度 | 在目标尺度内读得出主体树、辅助树、重叠群落与留口；冠幅统计与可见分量相符 | 三档冠幅存在但仍像均匀撒点：检查主体树的位置、群落轮廓、素材透明度、允许覆盖范围及有效像素，再调整；不直接全体放大或增加数量 |
| 草坪明暗 | 开敞面、林缘和中间调形成有方向的柔和关系，细纹理支持大块变化 | 每块中心都亮、边缘都暗，出现相似鼓包：重画宏观蒙版与范围；已有渐变应记录为组织重复，不误诊为完全没做明暗 |
| 材质与节点功能 | 铺地、屋面、种植、水体能通过材料与细部区分，醒目色彩对应明确对象 | 只有套叠色块、同一细纹理覆盖所有功能：先核实对象，再按部位工艺处理。颜色已由用户指定时保留色彩要求，通过材质和细部提高可读性 |
| 植物层次与活动 | 目标要求的地被、花境、乔木和设施形成前后关系，开口与活动面清楚 | 每区均匀铺花纹或随机撒人物：调整覆盖与聚散，将配景放到已有停留、行走空间；不为了丰富度新增未知设施 |
| 水岸、收边与光影 | 水陆接触、必要构件厚度和方向性投影可读，清淡风格仍保留局部层次 | 水池只剩蓝底加均匀外圈、所有接触处同样发白或影子漂浮：按岸型、对象和光向分别处理，避免一套内阴影或整体白蒙层 |
| 最终可读性 | 主体、边界与必要线稿在最终尺寸下清楚，局部素材清晰且接缝自然 | 降饱和或整体淡化后细部一起消失：回到局部色阶和遮挡关系调整，保持用户要求的外围留白 |

主节点、材料识别或空间主次有明显问题时，修正当前试铺再批量展开。执行者在已授权范围内自行复核；不要将常规试铺变成必须等用户批准的步骤。次要差异可在后续完善中解决，但需保留记录。功能确实缺失且无法从资料判断时继续其他明确部位，集中说明待核项。

## 保存实际验收依据

在本次输出目录保存一份 visual_review.json 或等价 Markdown，至少记录：目标版本与最终图像路径/哈希、表达依据、本图主次与色彩安排、实际使用的参考及作用（有则记录）、目标裁切范围与展示尺度、检查图片路径、各判据的位置观察与状态、修正动作及未解决项。表达依据区分用户要求、参考启发和执行者自主判断。试铺与最终检查分别记录；改图后对受影响判据重新查看最终导出，不能沿用旧预览的通过结论。

区分 requested_quality 与 achieved_quality。后者仅在技术核验与视觉检查完成后说明；有未解决的主要问题时不宣称达到所请求级别。不通过检查文件数量、素材数、冠幅统计、图层组存在或全部操作 done 自动推导视觉 pass。检查图片不存在或没有实际查看时写明未检查。

独立记录“工序与文件核验”“本图视觉质量”“参考适用特点的实现情况（如有）”。没有参考不降低本图质量要求，也不需要补一份虚构的参考检查。用户明确指出的平、灰、缺少重点等主要问题，列入本轮未解决项；不能通过改称“当前示意范围”或只检查新补细节消除它们。执行者修正并实际复查后更新状态，无需额外等待用户批准。旧版 pass 保留历史，但不能作为新一轮自动通过的依据。
