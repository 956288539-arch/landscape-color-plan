# 彩平素材使用规范 v1.2

基于用户提供的四套 PSD 编制：美丽乡村、居住区、现代景观彩总、现代公园简约风。适用于本项目后续 CAD 总图转彩平、Photoshop 填色、背景合成与过程记录。

## 1. 使用目标与依据

后续彩平以这四套 PSD 的真实材质、树冠、配景和图层关系作为表现依据。图面丰富度由地面纹理、植物层次、节点设施、水岸、建筑细节、明暗与主次共同组成。

各部位按完整合成工序处理，不能止于填入一张材质。四源实际图层、样式、填充、剪贴与调色的复核见 [分层工艺拆解](四套PSD分层工艺拆解.md)，操作配方见 [material-workflows.json](material-workflows.json)。

- 乡村源图：4134 × 2633 px，145 个图层及组，偏自然地景、山地、村落与低饱和氛围。
- 住宅源图：10100 × 5692 px，74 个图层及组，偏宅间景观、中心庭院、停车路网和建筑投影。
- 现代景观源图：3482 × 3308 px，48 个图层及组，偏曲线草坡、轻盈树冠、浅色步道和蓝绿水景。
- 城市公园源图：2149 × 4340 px，172 个图层及组，偏活动广场、花境花园、开敞草坪和公共配景。
- 完整清点见 `library/layer-register.csv`；来源校验见 `library/sources.json`；可调用素材见 `library/asset-index.json`。
- 当前素材库含 62 个 PNG 材质/配景与 16 个 JPG 组合参考。四张源图总览另行保留，共登记 439 个图层及组。
- 文中“源图参数”来自 PSD 实际读取；“建议起调值”是本项目图面表现约定，不是原图实测规划指标或施工设计标准。

## 2. 选择风格

| 模板 | 适用场景 | 主要语言 | 首选素材 |
| --- | --- | --- | --- |
| P 公园 / 乡村 | 自然型公园、山地、村落更新、河岸步道 | 橄榄绿、暖土褐、蓝灰水、低饱和植被、地形明暗 | P-G、P-W、P-P、P-D、P-T |
| R 住宅区 | 楼间绿地、宅前宅后、中心庭院、社区道路、配套滨水绿地 | 中深绿乔木、明亮草坪、灰白屋面、清晰投影、米白节点铺装 | R-G、R-T、R-W、R-P、R-F、R-V、R-H |
| M 现代曲线景观 | 曲线公园、建筑外场、草坡、水景节点 | 浅黄绿树冠、浅色流线铺装、蓝绿水、细线与柔亮氛围 | M-G、M-T、M-P、M-W、M-D、M-H、M-S |
| U 城市公园 | 城市公园、活动广场、口袋公园、花境花园 | 密叶乔木、暖米铺装、活动草坪、特色花境、家具与人群 | U-G、U-T、U-B、U-P、U-F、U-H、U-V |

乡村与山地默认 P；住宅及配套景观默认 R；曲线地形、水景节点默认 M；城市活动公园与广场默认 U。先选主模板再选素材。混合场景优先沿用主模板的色阶、投影和边界处理；跨库配景需在任务记录中说明。植物图片只描述外观，不据此认定真实树种。

## 3. 素材与表现方法的边界

1. **texture 材质**：净纹理采样块，置入目标项目新建的闭合区域蒙版。采样块均未验证无缝，铺大面积前必须检查接缝与重复图案。
2. **symbol 配景**：保留透明通道的树冠、树组、伞、躺椅、车辆和人物。按目标项目的尺度、功能与树位放置。
3. **reference 组合参考**：原图的裁切示例，用于理解层次与搭配。建筑、道路、河道、等高线、源楼号与标尺随新项目重建。
4. **source-only 源图信息**：原始蒙版、调整层、旧版本隐藏图层、标签和装饰保留在原 PSD 及图层登记中，不进入自动素材投放队列。

PNG 采样保留像素自带 alpha，**没有烘焙源图层总体不透明度、填充不透明度、全图调整层或剪贴关系**。调用时分别读取 `source_opacity_pct`、`source_fill_opacity_pct`、`source_blend` 与 `source_clipping`，并检查父组。Fill 与 Opacity 对样式的影响不同，不能简单互换。原始图层蒙版也不作为新项目的边界使用。

**图层效果也未烘焙进 PNG。** `source_effects` 保存效果摘要与有效开关；`source_composition` 指向完整样式、图案资源、剪贴和调色记录。外投影、内阴影、颜色叠加、图案叠加及描边各有作用，不能仅恢复树影。效果总开关和单项开关分别保留；图案须携带实际嵌入资源。源效果启用全局光时，其局部角度字段不能独立代表最终光向；源距离是源画布像素，不可直接当新项目米数。按目标尺度与统一光向重建，再对照组合参考。P-T01 已在像素中带有树影，需避免重复叠影。

住宅源 PSD 的图层名重复。查找必须用“源文件 SHA256 + 图层索引 / 图层 ID + 裁切坐标”，不能只按名称查找。索引是 psd-tools 读取顺序、从 0 开始、底部到顶部；Photoshop 界面顺序与其相反。

## 4. 公园 / 乡村素材规范

### 4.1 草地、林地与坡面

- **P-G01 橄榄绿草地**：大面积自然草坡、林地基底、乡村绿地。保留细颗粒，在分区蒙版内形成深浅变化。
- **P-G02 柔化自然植被**：林缘、坡面过渡、树下地面。与 P-G01 形成疏密和软硬对比，透明叠加于目标绿地范围。
- 地形线与坡地阴影依据目标项目提供的地形资料绘制。源图的卫星影像、等高线和梯田阴影只作为表现方法参考。
- 自然草地至少具有底色、可辨肌理与局部明暗。开敞草坪保持可读的连续面；已有种植图时，树位以种植图为准。

### 4.2 水域与滨水设施

- **P-W01 自然水波**：河流、溪流、自然池塘。源图为 **柔光 30.2%** 的剪贴纹理层，这是本库最应保留的合成关系。
- 水域使用蓝灰底色、水波纹理、水岸边缘分层。建议从源透明度起调，按输出大小控制波纹粒度。
- **P-D01 自然木纹**用于栈道和木质平台；**P-D02 浅金木板**用于局部重点节点。木纹沿实际行进或铺设方向。
- 只在目标方案有栈道、桥、平台时加入对应设施。水岸边缘必须与目标水域蒙版衔接。

### 4.3 乡土铺地

- **P-P01 / P-P02**：暖土褐村巷、入口和小广场。面积较大时用不同取样区与低强度纹理叠加降低重复。
- **P-P03**：冷灰细颗粒，适合步道、商业街、石质通道；源总体不透明度 **70.2%**。
- **P-P04**：中灰地面，适合道路、设施外场。主路、次路、小径以材质和明度分级。
- 原图源材料名称不等于实际工程材料规格；本规范中的名称只用于图面表现。

### 4.4 植物与氛围

- **P-T01**：浅色乔木，含烘焙树影，原图 67 × 77 px。用于村口、院落、巷口和远景点树。
- **P-T02 至 P-T04**：低饱和、半透明植被小样，适合小比例尺林缘氛围；原始像素仅 36 至 56 px 左右，保留小图使用条件。
- 近景清晰树冠不足时，标记素材缺口；不得把小图强行放大并标为高精度素材。
- 云雾压边、白鸟、红色印章属于可选展板氛围。默认施工或校核底图不启用；展示图也不得遮盖范围线、道路或标注。

## 5. 住宅区素材规范

### 5.1 绿地与树冠层次

- **R-G01**为住宅草坪基底；**R-G02**为明亮灌木 / 地被取样，只作局部种植层次。
- **R-T01**是深绿双株组；**R-T02 / R-T03**是中绿三株组；**R-T06**是小冠三株组。它们按“树组”调用，不能当作一棵大树缩放。
- **R-T04 / R-T05 / R-T07 / R-T08**分别作为浅绿、秋色、深绿、中绿单株，补充树组边缘与道路节奏。
- 秋色树用于少量点景。建议以种植冠层表现面积的 **5% 至 15%** 起调，而非全场同量混色。
- 住宅主要绿地以“草坪基底 + 地被 / 灌木层 + 乔木 / 树组 + 局部树影”组成。先确定开敞面，再沿建筑、步道、场地边缘组织植物。
- 源树层不透明度约 **50% 至 80%**，原参数逐项记录在素材索引。先在目标底色上试铺，避免把原始 100% 像素当最终显示强度。

### 5.2 中心庭院与水景

- **R-W01**用于中心水景或池面；**R-P01**用于米白池畔与会客铺装；**R-P02**用于局部颗粒铺装。
- 参考 **R-REF02**：水面、池岸、硬地、绿岛、坐席 / 遮阳伞和阴影共同形成节点。每种构件是否出现仍由目标方案功能决定。
- **R-F01**遮阳伞、**R-F02**躺椅组放在明确的休憩场地；不得侵占应保留的通行空间。
- 庭院细部与住宅建筑投影保持同一光向，不把纹理图自带的亮暗当作新的太阳方向。

### 5.3 道路、停车、人物与车辆

- 道路先服从 CAD 线稿，随后完成路面材质、路缘、停车线与植物界面。
- **R-V01**车辆只放在车道和明确停车位内，按目标图面尺度与方向摆放。
- **R-H01**俯视人物用于广场、步道、会客庭院，作为稀疏活动提示，不承担精细人物表现。
- 配景不能承担填补未知设计内容的作用。功能未明确的空地先完成合理底材与边界，保留方案判断空间。

### 5.4 建筑、主体与周边

- 参考 **R-REF04**：灰白屋面、屋面构件、檐口或女儿墙细线、建筑投影独立分层。
- 源建筑主投影层总体不透明度 **50.2%**。新项目建议以 **25% 至 50%** 起调，按目标光向和建筑几何重建。
- 投影不表示未经核实的日照分析。建筑高度、朝向或真实日照未知时，明确为示意表现。
- 周边以低对比度保持环境关系。用户要求只处理某地块时，全部彩色图层合并受该场地蒙版约束，场地外保留底图。

## 6. 现代景观与城市公园素材规范

### 6.1 M：现代曲线景观

- **M-G01 + M-G02**：细草纹基底与自然明暗叠加层。M-G02 源模式为叠加 100%，并使用剪贴关系；原始 PNG 单独打开较浓绿，最终应对照 M 总览校色。
- **M-T01 / M-T02 / M-T03**：中绿、疏透金黄、黄绿圆冠，原图层不透明度分别为 63.1%、76.9%、78.8%。比 P 系列提供更清晰的独立树冠，但仍受原始像素上限约束。
- **M-T04 粉白花树**：重点节点点景。少量布置在入口、转折或停留空间，避免全场平均撒布。
- **M-P01 浅灰条石**：台阶、亲水平台；**M-P02 暖褐斑驳**：局部嵌带。主路径的白色 / 浅色连续带应按目标几何重建。
- **M-W01 蓝绿水面**与 **M-D01 棕灰木板**：用于方案已有的景观池、木平台。**M-S01 水花**只用于明确存在的喷泉，不能用来替代普通水面细节。
- **M-H01 / M-H02**用于步道与平台；**M-V01**用于外围车道。源整体有亮化与边缘柔化，放在独立展示组；不得遮盖边界与入口。
- 参考 M-REF01 / 02：丰富度来自草地双层纹理、曲线铺装、目标地形线、乔木、水岸台阶与活动人物的配合。

### 6.2 U：城市公园与活动广场

- **U-G01 + U-G02**：细草地与明暗肌理，先形成可活动的开放草坪，再沿边缘布置树群。
- **U-T01 / U-T03**为中深绿和浅中绿密叶乔木，**U-T02**为黄绿点树，**U-T04**为浅绿行道树。前三者是同源冠形的变体；色彩变化不能代替冠形变化，连续布置需打散重复。
- 源 U-T01 的树影效果为正片叠底、不透明度 50%、距离 50 源像素、模糊 0 源像素。它描述源图的图层效果；新项目按目标尺度和统一光向调整，不作为固定套用值。
- **U-B01 黄绿花境 / U-B02 粉色花境 / U-B03 深绿地被**，用于步道侧、入口与特色花园；深绿作背景，黄绿和粉色作局部变化。这些小样仅 64 至 96 px，不应放大为近景精细植栽。
- **U-P01 浅米铺装**用于路径，**U-P02 暖灰拼石**用于活动广场，后者源不透明度 62%。**U-P03 碎石**源为叠加 100%，只作小块嵌带或过渡。
- **U-F01 桌椅组 / U-F02 长坐凳**布置在停留带；**U-H01 / 02**为草地休憩人物，**U-H03**为步行组。场地通行区域保持清楚，人物密度服从空间用途。
- **U-V01**为无源项目文字的接驳车身，仅用于明确有接驳车功能的道路。
- 参考 U-REF01 至 04：入口林荫、活动广场、开敞草坪、花境路径分别形成组合配方；台阶、坐墙、边界和水带均由目标方案重建。

### 6.3 四库混用与补足

| 主模板 | 可补入 | 条件 |
| --- | --- | --- |
| P 自然乡村 | M-T01 / M-T02 | 需要更清晰树冠时，降低饱和与对比，先试铺匹配 P 色阶 |
| M 曲线景观 | U-F、U-H、U-B | 目标具有家具、草地活动或花境功能；降低过强对比，保持轻盈植被基调 |
| U 城市公园 | R-F01 / R-V01 | 确有遮阳休憩或车行功能，统一尺度与光向 |
| U 城市公园 | M-D01 / M-W01 | 补木纹或水面，裁入目标蒙版并与 U 暖色铺装校色 |

U 源图中的桥与木平台较窄，当前保留为组合参考，没有把窄而带边缘的片段强作大面积木材贴图。项目需要时使用上表的跨库木纹配方，或回源 PSD 获取适合的新取样。只有外观证据的植物不自动赋予树种、花期或生态功能。

## 7. 图面丰富度标准

以下为本项目表现建议，不是源 PSD 的测量值。

| 等级 | 应达到的内容 | 使用场景 |
| --- | --- | --- |
| L1 材质基础 | 区域闭合、材质分区、底色与 CAD 对齐，场地内无遗漏 | 过程检查 |
| L2 完整彩平（默认交付） | 按目标完成地面肌理、植物层次、建筑细节与投影、水域 / 硬地边缘和节点；园内主次、明暗分量、色彩关系及主体与周边均可读 | 日常方案彩平 |
| L3 重点深化 | L2 基础上，重点节点增加更细铺装、设施与活动配景；全图统一材质尺度、色阶与光向 | 汇报展板 |

L2 的核对以“目标图中实际存在的空间类型”为分母；没有水景或建筑的项目不补画这些设施来凑项数。

效果参考可选，本图空间与色彩质量不依赖用户先提供准确样例。依据目标功能自主确定表达方向，再按 `skills/landscape-color-plan/references/focus-and-color.md` 和视觉验收逐项查看最终合成。细节增加、纹理齐全或彩色主体比外围醒目，均不能单独证明园内主次已经建立；用户指出的平、灰、缺少重点应单独复查。

**建议起调规则：**

1. 大面积草地至少有亮、中、暗三档可辨的宏观明暗，同一块较大草坪内组织开敞亮部和林缘暗部。细草纹、颗粒和树影不能代替草坪自身的色阶。
2. 有开敞草坪功能的区域，先保留约 60% 至 80% 的可读开敞面，再组织边缘树群；种植设计有明确规定时按设计。
3. 自然树组可从冠缘 15% 至 35% 的局部重叠起调；行道树按已有树位或明确序列布置。
4. 同一行中避免连续出现三次以上完全相同的树组组合；用单株与树组、深浅色阶、疏密关系形成变化。
5. 自由景观示意先分大、中、小树冠角色，再安排树群和位置；不能只在窄范围均匀随机缩放。以中型冠幅 D 为基准，小树约 0.55–0.75D、中树 0.85–1.10D、大树 1.25–1.65D 起调，均受目标设计与有效像素上限约束。规则树阵按设计处理。
6. 已有烘焙阴影的素材统一方向。不能任意旋转或镜像后产生多重光向。
7. 每个明确的重点节点至少检查三种互相配合的表现层，例如铺装 + 种植 + 坐席，或水面 + 水岸 + 平台。
8. 丰富度从重点节点向过渡空间、背景递减；树群间保留疏段、留口和草坪口袋，避免等距满边或围成连续整圈。

构图参数集中维护在 [visual-composition.json](visual-composition.json)，适用于四套风格中的示意表现，明确设计优先。详细方法见 [构图与色阶](../skills/landscape-color-plan/references/art-direction.md)。在最终整图缩略预览中也应能看出冠幅主次和草坪深浅；统计、图层数和细噪点不作为美感已经达标的依据。

## 8. 图层与调用流程

推荐从下到上保留这些图层组：

`00 CAD底图 → 01 场地蒙版 → 02 地面底色 → 03 材质肌理 → 04 水域水岸 → 05 植物 → 06 建筑细节 → 07 投影 → 08 节点设施与活动 → 09 CAD轮廓与标注 → 10 调色与展示效果`

植物与建筑投影可以按遮挡关系拆分上下层。关键是底色、纹理、阴影、配景、线稿可独立修改，最终合成不能将结构性信息遮没。

1. 确认目标 CAD、场地范围、图幅和已知尺度，保留源图副本或版本。
2. 选择 P、R、M 或 U，读取风格配置与素材索引，按空间角色建立素材清单。
3. 先选包含草坪、树群、步道及边角的典型局部试铺，检查整图缩略预览中的冠幅主次、疏密与大块明暗，再检查 100% 局部的透明边缘、肌理、线稿配准和素材清晰度。
4. 用目标闭合区域建立新蒙版，铺底色与材质，再布植物、水岸、建筑和设施。
5. 材质做柔化拼接时保留原素材 ID 与变换记录；没有经过接缝检查的取样块不能标为无缝贴图。
6. 最后完成投影、轮廓、标注和有限的调色，做全图与 100% 局部检查。
7. 保存分层 PSD、预览图、`used_assets.json`。用户需要时，再导出实际逐步填色阶段的 20 秒过程视频。

**尺度说明：**PNG 的宽高是像素，不是米。用目标 CAD 中可信的已知长度计算像素 / 模型单位；DPI 只影响打印尺寸。位图原则上缩小使用；大于原始像素的需求须做 100% 检查或补充更清晰素材。技术调用注意事项另见《自动调用约定》。

## 9. 验收清单

- 所有目标景观区都已核对，包括场地边缘、转角和左下等易遗漏区域。
- 颜色、材质和树影均受目标场地 / 对应分区蒙版约束。
- 草地、水、硬地、屋面的材质角色明确，局部样式与选定模板一致。
- 树组没有被当作巨型单树；人物、车辆与设施在对应功能空间内。
- 没有明显透明边缘杂色、切边、拉伸、拼接缝、重复棋盘或低清放大。
- 全图光向一致；真实地形、标尺、楼号和建筑位置来自目标资料。
- 调色与装饰没有遮挡 CAD 边界、出入口、道路和必要标注。
- 分层 PSD 能重新打开，素材使用记录可回溯到素材 ID 与源文件。

## 10. 更新与扩展

v1 素材库提供四套风格的草地、铺地、水纹、木纹、树冠、树组、花境取样、桌椅、坐凳、人物、车辆和喷泉水花。高分辨率花卉、不同冠形乔灌、精细廊架和运动设施的独立素材仍可继续补充。新增素材先做来源、类型、像素、透明度、图层效果、光向与适用场景检查，再分配新 ID；不覆盖已有 ID。

源 PSD 修改后重新计算 SHA256、更新图层登记与裁切坐标。已经导出的素材以各自文件哈希复核。未来任务只要在本项目中执行，就先读取本规范、风格配置及素材索引。
