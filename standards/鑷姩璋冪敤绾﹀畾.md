## 执行顺序

1. 依据用户要求、目标功能与展示用途确定表达方向，并根据场景选取主模板（rural、residential、landscape 或 park）。效果参考可选：明确参考用于校准适用表现，大致意向用于提取相容特点，无参考时自主组织主次、色阶与配色；不因缺少效果参考停工。打开库内总览及对应节点作为工艺补充，再按 `roles` 检索素材。关键区域先按目标资料识别功能与材料，泛称 NODE 的图层、套叠曲线和参考色样不作为唯一功能依据。
2. 只自动导入 `kind=texture` 或 `kind=symbol` 且 `approved=true` 的条目。`reference` 只用于视觉对照。
3. 对照 `pixel_size`、`source_opacity_pct`、`baked_shadow`、`symbol_units` 和使用范围，先做局部试铺。
   在试铺前将视觉角色与色彩职责落实到目标分区，按构图参数安排树群覆盖、主树、留口与草坪连续明暗。选最影响主图的节点连同邻接空间，先看简化块面主次，再看完整材质合成，通过本图独立视觉检查后批量展开；有适用参考时同时比较。边角试铺不能代替主节点。参数只是起调值，明确种植设计优先；执行者自行检查，不额外增加用户审批。
4. 新项目几何只从新项目 CAD 或设计资料生成。材质图不能决定场地、楼体、道路、水系或等高线形状。
5. 导入 PNG 时保留原 alpha；分别读取 Opacity、Fill、父组、混合方式及剪贴关系。按部位工序继续完成局部塑形、收边、配景投影和调色。读取 `source_composition` 核对完整效果与开关；图案叠加要恢复实际资源。贴图全部裁入新项目蒙版。
6. 保存素材 ID、放置位置、缩放、角度、不透明度、蒙版 ID 和源文件哈希到 `used_assets.json`。

## 几何、单位和边界

- 源 PSD 图层索引是 psd-tools 的底部到顶部顺序，从 0 开始；优先同时记录源 layer_id 和 SHA256。不能将其直接当作 Photoshop 界面的序号。
- 原始素材裁切坐标为源 PSD 的画布像素坐标；PNG 的本地原点是裁切框左上角。
- `texture` 当前均为普通取样块，`verified_seamless=false`。平铺前做接缝试验；如作派生贴图，保留母素材 ID。
- 从 CAD 到画布应保存可逆仿射变换。不得用屏幕截图的缩放比例代替已知 CAD 长度。
- 本机 Photoshop 2024 的路径点数值输入曾观察为点单位：像素坐标输入时需乘 `72 / document.resolution`。每次正式绘制前先创建 100 × 100 px 校验框，读取实际选区边界验证；不要把这一行为假定为所有版本通用。
- 场地外只保留底图时，所有彩色组统一受场地蒙版约束；边界线及抗锯齿按实际线宽设置检查容差。

## 默认质量与记录

- 目标强调体积时先核对高度与功能依据，按对象选择分层绘制、局部简模或混合方式；按对应指南核验树冠风格、受影关系与渲染配准。规范已写入、工具已具备、实际试铺已通过分别记录，不能互相替代。
- 默认目标完成度为 L2，实际达到的级别须经视觉与技术核验。经目标确认没有该功能可记“不适用”；尚未识别功能保留 pending，不为提高完成度而新增设施。
- 记录树冠角色、可见冠幅、草坪明暗配置及缩略图检查；细纹理或数量达标不能替代视觉层次。
- 各部位记录 workflow_id、operation_id、实际图层 / 蒙版、参数、operation_evidence 及 pending / done / not_applicable 状态。逐项核对职责与执行证据；不以父组存在为全部工序统一记 done。
- 操作执行与视觉判断分开记录。保存 visual_review.json 或等价 Markdown，独立检查最终导出版本的园内主次、明暗分量、色彩关系、树群、草坪、材质、光影及未解决项；有适用效果参考时另检查所采用的表现特点。用户指出的主要问题不因补齐细节或重新限定质量范围而自动解决，实际修正后再声明达到所请求的完成度。
- 树组的 `symbol_units` 是组内可见树冠数，用于控制疏密，不能作为树种或实际株数设计依据。
- 同一方向的烘焙树影不要任意旋转 / 镜像。需要不同方向时优先选择合适原素材或分离阴影后单独生成。
- 图面中的真实楼号、文字、标尺、指北针、地形线由目标资料生成。
- 过程视频保存实际逐步填色 / 合成阶段画面。使用阶段图合成时，在交付说明中写明，不称为鼠标桌面录屏。
